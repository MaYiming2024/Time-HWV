Time-HWV (Time-dependent Hydrogen Wavefunction Visualizer)
===========================================================

Version: 1.0
Author: Yiming Ma
Email: 2024111042@stumail.nwu.edu.cn
Repository: https://github.com/MaYiming2024/Time-HWV

Description:
------------
Time-HWV is an open-source Python toolkit for visualizing the time-dependent
phase dynamics of hydrogen atom wavefunctions. It explicitly decouples and
animates the real part, imaginary part, and probability density in synchronized
2D and 3D views.

Contents:
---------
- cli_main.py
- gui_main.py

Requirements:
-------------
- Python 3.13+
- NumPy, SciPy, Matplotlib (required)
- Plotly (optional, for 3D volume rendering)

For Windows users without Python, pre-compiled executables are available:
- cli_main.exe      : Command-line interface
- gui_main.exe      : Graphical user interface
